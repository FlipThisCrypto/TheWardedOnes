
# THE WARDED ONES TCG – CLASS BIBLE

This document defines all playable character classes in The Warded Ones TCG.
Classes determine a card's identity, statistical bias, and ability pool.

Every Mage must belong to one class.
Fighters and some advanced Beasts may also adopt class identities.

Core influences of class:
- Base stat bias
- Ability pool
- Evolution flavor
- Strategy archetype

STAT DEFINITIONS

HP
Total health before the unit is defeated.

Attack
Raw offensive damage.

Defense
Damage reduction value.

Speed
Turn order priority.

Cost
Resource required to play the card.
